# Deployments 配置界面

部署列表和创建／编辑弹窗参考 Claude Console 的信息结构，使用仓库现有 shadcn/ui Base UI 组件与语义主题令牌。API、鉴权、workspace 路由和部署执行合同保持不变。

## 界面与状态

- 列表与 Environments、Vaults、Memory 使用同一套无外边框表格和页头间距。触发器展示本地化频率、时间和 IANA 时区，自定义表达式直接显示 Cron。空或空白 `expression` 显示手动，避免空白触发器。空列表用与页头相同的“创建部署”语句说明路径，筛选无结果时提示调整条件。
- 创建与编辑共用配置、资源、触发器三个分区。桌面为左侧说明、右侧表单；窄屏改为单列。内容独立滚动，标题和提交按钮固定可达。
- 配置区保留名称、Agent、环境和初始消息；资源区保留可选凭据保险库、文件、Git 仓库与记忆存储。Agent 详情入口继续锁定当前 Agent 及版本。
- 编辑时资源列表为空，直接提供“添加资源”，打开菜单不标记资源已改动；实际添加或修改后才进入资源提交。已有资源保留“替换资源”入口、替换说明及“保留现有资源”，取消替换后恢复原始资源；未修改的资源仍从更新请求中省略，保护未知字段与服务端凭据。
- 新建默认手动运行，切到定时时默认工作日 09:00 和浏览器 IANA 时区。手动／定时切换保留未提交排程草稿。
- 图形化频率支持每分钟、每小时（选择分钟）、每天、工作日、每周（选择星期）。点击时间字段会打开 shadcn/Base UI Popover，使用小时（00–23）和分钟（00–59）Select 选择精确时间；选择即时回填并更新 Cron 与预览，完成、Escape 或点击外部可关闭。字段按当前语言显示时间，内部保持 `HH:mm`。时区使用可搜索的 Base UI Combobox。
- 图形化字段生成五段 Cron。“编辑 Cron”保留当前表达式并进入自定义模式。编辑既有部署时仅将完全匹配的表达式映射成图形控件，其他表达式原样保留。
- 所有用户文案进入 `en` 和 `zh-CN` 字典，星期、时钟与预览日期使用当前 locale。IANA 标识和 Cron 保持协议形式。字段 ID 使用 React `useId`，不依赖翻译文本。

## Agent 选择器

创建会话和创建／编辑部署共用可搜索 Agent 选择器。选项每页 20 条，滚动接近列表底部或点击“加载更多”时才请求 `next_page`，保留已有选项并按 ID 去重。支持按名称进行服务端分页搜索，完整 Agent ID 则直接检索；已归档 Agent 不作为可选项。搜索输入防抖 300ms，工作区与搜索词分别隔离查询缓存，切换搜索重置列表滚动位置。分页失败保留已加载选项并提供重试；选中项不因搜索切换或关闭弹层而丢失。Agent 详情入口仍锁定指定 Agent。

## 排程预览与提交

`deployment-schedule.ts` 使用 cron-parser 解析 POSIX 表达式，使用 Luxon 解析指定时区的墙上时间。先在 UTC 中枚举日历 occurrence，再解析目标时区，以对齐后端 robfig 的夏令时语义：不存在的时间跳过，重复的时间返回两个 UTC 时刻。预览显示未来五次运行，每分钟刷新；闰日计划不受一年窗口限制。

前端拒绝非五段表达式、无未来 occurrence 和无效时区，并与 `deploymentjobs.Parse` 使用同一套字符过滤（`L` `W` `#` `?` `@`）：`WED`/`JUL` 在预览阶段即拒绝，`THU` 不含这些字符因而可预览。另拒绝 Jenkins `H` 字段，避免 parser 放行而后端 robfig 失败。错误就地展示，定时配置无效时禁用提交。后端仍是参数校验和执行的最终权威；浏览器与服务器使用各自的 IANA 时区数据。

提交沿用现有 `ManagedEntityFormValues` → API 映射：手动为 `schedule: null`，定时为 `{type: "cron", expression, timezone}`。初始事件、资源引用和 Agent 版本映射不变。本次没有预算字段对应的后端支持，因此不提供预算输入。

详情标题24px、分区标题复用DetailCard的16px、正文14px、元信息12px，页面最多四档。概览按原有卡片组织，字段名保持正常大小写，分隔采用0.5px。运行记录标题无需再加重复说明，部署自身描述保留。

运行记录复用DetailTableCard/NestedRows与共享Table，所有状态的边界0.5px。每列至少128px，在表格现有滚动容器内横向查看，避免窄屏把状态和时间挤成省略号；滚动条复用subtle-scrollbar并跟随主题。API字段、运行状态推导、运行顺序、会话链接和执行逻辑不变。

实际ManagedEntityDetailPage静态数据样本覆盖非空、空态、错误，中英、明暗和390px；没有创建或运行真实部署，不能当真实部署链路验收。详情编辑入口已复用列表使用的ManagedEntityDialog，Agent/环境使用相同选择器，配置、资源与触发器遵循相同字段和校验。取消/关闭后焦点回到编辑按钮。

详情保存沿用updateManagedEntity与既有请求映射。成功使用返回实体刷新页头并关闭弹窗，保留背景和运行记录，避免退出期间重新进入整页加载；非部署详情的原刷新行为保持。失败保留弹窗草稿，显示错误并允许重试。新增组件回归覆盖取消无写入、保存失败/重试、初始消息/排程保留、资源未改变时不回写和关闭焦点；浏览器静态样本不执行真实保存。

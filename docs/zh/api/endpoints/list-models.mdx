---
title: "列出模型"
description: "查询当前工作区公开的模型 ID。"
api: "GET /v1/models"
---

返回当前工作区配置的模型 ID，API 调用会原样使用这些 ID。

## 响应

<ResponseField name="data" type="array">
  模型对象列表。
</ResponseField>

<ResponseField name="data[].id" type="string">
  调用 API 时使用的模型 ID。
</ResponseField>

```json 响应
{
  "data": [
    {
      "type": "model",
      "id": "kimi-k2.5"
    }
  ]
}
```

工作区未配置 LLM Provider 时返回 `503`。客户端应使用稳定的 `error.code` 判断该状态，不依赖可读文案：

```json 503 响应
{
  "error": {
    "type": "api_error",
    "code": "workspace_llm_provider_not_configured",
    "message": "This workspace has no LLM provider configured"
  }
}
```

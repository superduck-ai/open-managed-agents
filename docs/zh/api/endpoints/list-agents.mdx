---
title: "列出智能体"
description: "分页查询当前工作区中的智能体。"
api: "GET /v1/agents?beta=true"
---

列出当前工作区中可见的智能体。该资源当前要求 `beta=true`。

<ParamField query="beta" type="boolean" required>
  必须为 `true`。
</ParamField>

<ParamField query="limit" type="integer">
  返回数量上限。最大值为 100。
</ParamField>

<ParamField query="page" type="string">
  上一页返回的不透明游标。
</ParamField>

<ParamField query="include_archived" type="boolean">
  是否包含已归档智能体。默认不包含。
</ParamField>

<ParamField query="created_at[gte]" type="string">
  只返回在该 RFC 3339 时间或之后创建的智能体。
</ParamField>

<ParamField query="created_at[lte]" type="string">
  只返回在该 RFC 3339 时间或之前创建的智能体。
</ParamField>

```bash
curl 'http://localhost:38080/v1/agents?beta=true&limit=20' \
  -H 'Authorization: Bearer sk-ant-local-default' \
  -H 'anthropic-version: 2023-06-01'
```

响应中的 `next_page` 为 `null` 时表示已经到达末页。

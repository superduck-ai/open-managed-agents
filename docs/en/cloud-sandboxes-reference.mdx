Cloud environments use an E2B or compatible runner configured by the operator. The image, tools, versions, and resources depend on the deployment. Self-hosted environments use the environment supplied by their own worker.

This inventory references [managed-agent-sandbox main](https://github.com/superduck-ai/managed-agent-sandbox/tree/811f3db0a66282ec69b90983a8af429b970bd961), at commit `811f3db0`. It describes that image's build recipe; it does not imply that every OMA deployment uses that image. Ask your operator which template and image are in use.

## Base runtime

This version is based on Ubuntu 24.04 and builds for `linux/amd64` and `linux/arm64`. Its base runtime includes:

| Category | Tools and versions |
| --- | --- |
| Languages | Python 3.13.14, Node.js 24.18.0, Go 1.26.5, Java 25.0.3, PHP 8.5.8, Ruby 3.4.10, Bun 1.3.14, Rust 1.97.0, GCC/G++ 14.2.0 |
| Package and build tools | pip, uv, npm, Yarn, pnpm, Cargo, RubyGems, Bundler, Composer, Maven, Gradle, make, CMake |
| Databases | SQLite, PostgreSQL client `psql`, Redis client `redis-cli` |
| Command line | Git, curl, wget, jq, ripgrep, SSH client, tar, zip, unzip, tmux, screen, vim, nano, tree, htop |
| Other | Docker CLI and Claude Code; Docker also requires access to a Docker service. |

`psql` and `redis-cli` connect to external services; their presence does not mean PostgreSQL or Redis servers run in the sandbox. External connections also depend on network policy and the destination configuration.

## Document, data, and multimedia tools

The repository's default build ends at the `toolkit` stage, which adds:

| Use | Tools |
| --- | --- |
| Documents | LibreOffice, Poppler, qpdf, Pandoc, Typst; Python packages `python-docx`, `python-pptx`, `openpyxl`, `pypdf`, `pdfplumber`, `reportlab` |
| Data and charts | `pandas`, `numpy`, `matplotlib`, `xlsxwriter` |
| Graphics and browser | Graphviz, PlantUML, D2, Mermaid CLI, Playwright and Chromium Headless Shell |
| Image, audio, video and OCR | ImageMagick, FFmpeg, SoX, Tesseract (Simplified Chinese and English), eSpeak NG, faster-whisper and the Whisper Small model |
| Other | GitHub CLI (`gh`) |

These toolkit tools may be absent if the deployment uses the base `runtime` stage, an older version, or a custom image. Consult the image repository's [`versions.env`](https://github.com/superduck-ai/managed-agent-sandbox/blob/811f3db0a66282ec69b90983a8af429b970bd961/versions.env) and lock files for version details.

## Inspect your environment

Run these commands in a session sandbox to inspect its OS, architecture, and common tools:

```bash
cat /etc/os-release
uname -m
python3 --version
node --version
go version
for tool in libreoffice pdftotext tesseract ffmpeg dot mmdc; do
  command -v "$tool" || echo "$tool: not installed"
done
```

CPU, memory, disk, networking, and package preparation depend on the [environment configuration](/docs/en/environments) and deployment. Use `nproc`, `free -h`, and `df -h` to inspect the current sandbox; other environments may differ.

## Idle and recovery

An idle cloud sandbox can be reclaimed according to deployment configuration. A later input can trigger a replacement, but OMA does not checkpoint the entire sandbox: local working directories, temporary files, background processes, and temporarily installed packages can be lost. Conversation history, committed persistent files, and remounted resources have their own lifecycles. Write deliverables to `/mnt/session/outputs/`, then view and download them using the [files guide](/docs/en/files).

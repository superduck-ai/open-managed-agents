---
title: "获取会话"
description: "读取会话当前状态、智能体快照和资源。"
api: "GET /v1/sessions/{session_id}?beta=true"
---

返回当前工作区中的一个会话。该资源当前要求 `beta=true`。

<ParamField path="session_id" type="string" required>
  `sesn_` 开头的会话 ID。
</ParamField>

<ParamField query="beta" type="boolean" required>
  必须为 `true`。
</ParamField>

<ResponseField name="id" type="string">
  会话 ID。
</ResponseField>

<ResponseField name="agent" type="object">
  创建会话时保存的智能体快照。
</ResponseField>

<ResponseField name="environment_id" type="string">
  运行该任务的环境。
</ResponseField>

<ResponseField name="status" type="string">
  当前生命周期状态，例如 `idle` 或 `running`。
</ResponseField>

<ResponseField name="resources" type="array">
  会话当前挂载的资源。
</ResponseField>

<ResponseField name="usage" type="object">
  聚合使用量。
</ResponseField>

<ResponseField name="stats" type="object">
  会话运行统计。
</ResponseField>

<ResponseField name="vault_ids" type="array">
  创建会话时授权的密钥库引用。
</ResponseField>

<ResponseField name="outcome_evaluations" type="array">
  当前结果评估状态。
</ResponseField>

```bash
curl 'http://localhost:38080/v1/sessions/sesn_01...?beta=true' \
  -H 'Authorization: Bearer sk-ant-local-default' \
  -H 'anthropic-version: 2023-06-01'
```

<Note>
  读取会话只返回当前快照。需要增量进度时，请使用 `/events`、`/events/stream` 或线程流接口。
</Note>

# 公共预置技能

本目录独立维护 OMA 随程序分发的公共技能，包含 Excel、PowerPoint、PDF、Word 和归藏网页 PPT。

`catalog.json` 声明技能 ID、展示名称、图标和源码目录；`catalog.go` 将文件嵌入程序。服务启动时自动注册，运行时无需联网获取技能，也无需手动上传。修改源码后重新构建即可发布新内容。

项目预置技能可上传更新、选择图标及上下架，技能本身不能删除。上传版本覆盖项目版本，重启或升级保留覆盖；选择“恢复预置版本”回到项目当前自带的版本，并保留图标及上下架选择。没有覆盖时，升级自动使用项目新版本。手动上传的其他系统技能仍可删除。技能使用的 Python 库、Office/PDF 工具和字体由执行环境提供。

来源与许可证见 [UPSTREAM.md](UPSTREAM.md)。归藏项目中未被运行文件引用的宣传图 `assets/ppt-skill-showcase.png` 不纳入分发；运行用模板、背景素材、脚本、参考资料及许可证保留。

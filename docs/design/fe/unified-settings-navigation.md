# 统一设置导航

## 入口与分组

控制台保留概览、快速开始、智能体、会话、部署、环境，以及可折叠的资源组。资源默认折叠，由用户点击展开，进入资源页面或改变窗口尺寸保持手动选择的状态。渠道归入资源，固定放在技能下方；其余子项沿用当前中英文名称的显示宽度排序，并使用固定顺序避免选中加粗时跳位。中文依次为文件、技能、渠道、记忆存储、MCP 隧道、Webhooks、凭据保险库、MCP 服务器；英文依次为 Files、Skills、Channels、Webhooks、MCP tunnels、MCP Servers、Memory stores、Credential vaults。展开列表与紧凑菜单共用排序，图标和文字左对齐。侧栏底部的设置是完整配置的统一入口。

设置沿用同一外壳、顶部搜索和工作区切换器，按四组组织：

| 分组 | 页面 | 作用范围 |
| --- | --- | --- |
| 模型与访问 | LLM 模型、API 密钥 | 模型默认展示当前工作区目录，可切换组织共享配置；密钥属于当前工作区 |
| 用量与运行 | 用量、成本、可观测、OpenTelemetry | 用量和成本是组织报表，可筛选工作区；可观测属于当前工作区；遥测目标属于组织 |
| 组织管理 | 成员、工作区目录、组织资料 | 当前组织 |
| 个人设置 | 个人资料、外观与语言 | 当前账号 |

组织管理子项按名称长度从短到长排列为成员、工作区、组织资料，中英文及紧凑菜单共用此顺序。

设置侧栏与主导航共用 36px 行高、14px 字号、18px 一级图标和 16px 子项图标。返回应用与分组之间留 12px，设置分组之间留 8px，展开子项上下各留 4px，组内行间距为 4px。

设置侧栏一次展开一个分组。首次进入模型与访问，之后记住最后访问的页面。当前页所属分组变化时（搜索跳转、旧链接重定向或直接输入 URL）自动展开该分组。点击分组展开或收起，点击子页切换内容和面包屑，与主侧栏资源组交互一致。分组和子页复用 Sidebar 菜单控件，统一图标、字号、行高、右侧展开箭头、悬停和选中背景。当前页所在分组收起时在分组上显示选中背景，展开时在子项上显示选中背景。手机端切换分组保留抽屉，选择子页后关闭抽屉。

主导航、资源、设置分组及子页各自使用唯一的模块图标，统一来自 `productIcons`。模型与访问使用调节滑杆，用量与运行使用仪表，组织管理使用机构建筑，个人设置使用用户齿轮。子页分别使用芯片、钥匙、用量柱图、钱包、活动曲线、遥测信号塔、成员、组织楼宇、工作区面板、个人和调色盘。渠道使用 Infinity 双环图标，表达持续连接与双向流转。搜索页面结果、资源结果与紧凑菜单沿用对应模块图标。

## 范围、权限与兼容

进入设置时侧栏导航从右侧 24px 淡入，返回应用时从左侧 24px 淡入，两者统一为 240ms ease-out。动画绑定到实际的 settings/main 导航容器，只在进入/离开设置或切换组织时重放；设置子页之间切换保持同一导航实例，不重放入场动画。系统开启减少动态效果时均关闭动画。

页面目录集中在 `shared/navigation/`（`navigation.ts`、`navigation-paths.ts`、`settings-navigation.ts`），供侧栏、搜索和页面访问判断共用；顶栏位于 `features/console-topbar/`，外壳样式位于 `shared/ui/console-navigation.css`，响应式折叠位于 `shared/hooks/use-responsive-sidebar.ts`，文档链接统一由 `shared/documentation.ts` 生成。共享目录不反向依赖功能页面或应用外壳。权限谓词位于 `shared/permissions/`，导航目录负责路由到权限的映射。组织资料和工作区目录需要当前组织的 `organization:manage`，成员需要 `members:manage`；用量和成本分别需要 `usage:view`、`cost:view`。无可访问子页的分组不显示。直达受限页面展示无权限状态，后端鉴权继续作为最终边界。

LLM 模型只保留一个设置导航入口，默认进入 `/settings/workspaces/{workspaceId}/llm`，合并展示当前工作区专用与组织共享 Provider。直接访问 `/settings/llm` 使用替换导航进入当前工作区目录。页内范围导航可进入 `/settings/llm/organization` 管理组织共享连接；组织与工作区作用域共用“LLM 模型”标题。组织 Provider 在工作区目录中保持只读，其管理链接指向显式组织配置。旧 `/llm-models` 使用当前工作区，旧 `/workspaces/{workspaceId}/llm-models` 保留地址中的工作区，均替换跳转到规范工作区模型设置地址。切换工作区时更新工作区模型地址并清除旧表单草稿；组织配置地址与草稿保持不变。切换模型范围保留查询参数和 hash，清除上一范围的表单草稿。保存后仍按快速开始的合法返回参数回到对应工作区的快速开始；返回参数只接受指向该工作区 `agent-quickstart` 的站内相对路径，其余一律忽略。旧成员链接跳到组织成员；旧工作区遥测链接跳到组织遥测目标，跳转前也使用组织遥测对应的设置分组、面包屑和作用范围。旧链接重定向保留查询参数及 URL hash；hash 按路由器解析后的原值透传，不再二次编码，避免 `%25`、`%5C` 等被保留的转义序列被重复编码。MCP 隧道、Webhooks 和 API 密钥保持现有 URL 与 API，不能因为 URL 以 `/settings/workspaces/` 开头就将它们视为组织工作区目录。

组织遥测维护目标与工作区覆盖范围。编辑说明明确共享目标修改会影响覆盖范围内的工作区。没有新增第二套工作区遥测管理入口；旧后端资源合同不变。

切换工作区时，工作区内容按新范围重新挂载；组织和个人设置保持当前页面。用量与成本是组织报表，工作区只是筛选条件：侧栏切换工作区不重置报表筛选，只有组织变化或旧 `/workspaces/{id}/cost` 路由工作区变化才重置工作区、模型、密钥和会话筛选。切换期间原页面不可交互，成功后恢复。组织变化仍重新挂载应用内容。文件详情使用路由工作区标识，在该工作区与当前请求作用域一致后才加载元数据或允许下载；同步 URL 已指定的工作区时保留详情路径。设置页、重定向壳及其设置目标页均跳过返回来源记录，其中包括旧 billing 地址。工作区 Webhooks 与 MCP 隧道继续作为应用资源记录来源。读取历史来源时过滤已污染的设置或重定向地址，原应用来源已丢失时回退概览。返回应用保留进入设置前的路径、查询和 hash；若工作区已经改变，则退回新工作区的对应目录，去掉旧资源 ID。

账号菜单保留组织切换、外观、语言、退出和独立的平台管理入口。组织邀请统一从顶栏通知进入，账号菜单仅查询组织切换所需信息。语言选项与外观设置页共用语言原名，始终显示 English 和简体中文。超管后台保留独立的平台导航与权限边界。账号菜单入口和后台侧栏静态标题统一命名为“超管后台”，返回入口为“返回超管后台”。后台复用 52px 顶栏、品牌、居中搜索与文档入口、Slate 2 导航表面、圆角内容面板和响应式侧栏，1040px 以内自动切换图标栏，手机使用抽屉。侧栏顶部标题只表达平台级作用范围，使用普通静态容器；组织管理、超级管理员、系统技能及返回工作台承担导航。

## 顶栏、搜索与邀请

顶栏高 52px，含品牌、搜索、文档和邀请提醒。Logo 在普通控制台、设置和超管后台均返回应用首页 `/dashboard`。侧栏展开时，搜索框中心取窗口中心与内容面板中心的中点，使宽屏下的品牌、搜索和右侧操作保持视觉平衡；224px 侧栏下相对窗口中心右移 54px，204px 侧栏下右移 49px。图标栏模式继续对齐内容面板中心；手机端搜索框填满菜单与右侧操作之间的可用空间。顶栏与侧栏共用 Slate 2 表面，内容位于独立的圆角面板中，桌面圆角 16px，手机圆角 12px，外侧保留 6–8px 留白。内容在面板内滚动。取消桌面手动折叠按钮；宽度不超过 1040px 自动切换图标栏，手机端使用现有 Sidebar 的抽屉断点（768px）。图标栏的分组通过菜单访问子页。

会话详情使用独立的全高内容布局，页面外壳仅保留顶部间距，左右间距由会话标题与工具栏自行提供；检查器贴合内容面板右侧和底部，外壳不预留纵向滚动条槽。控制台内的右侧 Sheet 共用顶栏高度、面板外侧留白和圆角，顶部从 52px 内容边界开始，右侧与底部对齐内容框。此规则覆盖智能体、会话快速查看、环境预览、技能、MCP、Webhook、工作台与超管系统技能；环境可拖拽预览的最大范围受当前内容区宽度约束。手机右侧详情保留两侧 6px 留白，正文独立滚动，关闭与底部操作可达。

超管后台共用相同的搜索弹层、单行结果、快捷键和响应式尺寸。搜索范围包含有权限的组织管理、超级管理员和系统技能页面，以及组织名称、UUID 和文档。组织查询使用既有平台客户端及 `/api/platform-admin/organizations` 的服务端搜索和游标分页，缓存按平台账号隔离，取消与撤权沿用后台守卫。

搜索组合共享 Dialog 和 cmdk Command：

- 搜索页面、可访问工作区、文档和当前工作区的资源；不索引 API 参考或接口端点。
- 17 篇中英文指南的标题和摘要来自仓库文档，索引维护在 `features/console-search/documentation.json`。文档链接统一使用 `https://oma.mintlifysite.com/docs/{zh|en}/{slug}`，顶部文档入口同样包含 `/docs/` 前缀。指南改名或移动时同步索引，测试同时核对公开 URL 前缀和仓库文档路径。
- 资源调用现有列表/搜索接口，范围包含账号、组织和工作区。智能体和 MCP 服务器使用服务端搜索；会话、部署、环境、记忆存储、保险库、文件、技能在已加载分页内匹配名称或 ID，用户可继续加载后续页。不会读取保险库密钥值或 API 密钥值，也不将资源内容发往外部搜索服务。
- 输入防抖 200ms，异步结果不沿用旧查询。部分资源失败或查询出错时显示重试提示，并隐藏“无匹配结果”空态，不把失败当作无结果。
- 每条结果固定 44px，使用对应模块图标，一行显示名称和上下文，长内容省略。页面结果显示所属分组，顶级控制台页面不附加上下文；资源结果显示资源类型（如“环境”“智能体”）。两者都不重复当前工作区名，避免把类型或范围误读为名称或状态。页面权限过滤也适用于最近访问。
- 搜索输入区使用整行样式，右侧提供关闭按钮，底栏仅显示选择、打开、关闭快捷键引导。弹层桌面最大宽度 672px，1100px 以内收紧为 600px，手机保留两侧 12px 留白。结果区高度随视口收紧到 400px、352px 或 320px 上限。
- ⌘/Ctrl+K 开关、Escape 关闭、方向键与 Home/End 由 cmdk 处理。选择到边界不循环，滚动保持在结果列表内。鼠标和键盘共用同一选中状态，无独立 hover 高亮。
- 查询保留到下次打开，最近访问仅保存在内存，切换账号/组织/工作区后清除。

邀请列表每 60 秒刷新一次，打开通知弹层时主动刷新。处理成功后取消进行中的列表查询，移除已处理项并失效重取，迟到的旧响应由 TanStack Query 的取消机制丢弃。邀请详情打开时初始焦点落在弹窗容器，用户需主动选择接受或拒绝；关闭后焦点返回通知按钮。

提醒数字来自 `/api/invitations` 的待处理数量，超过 99 显示 99+。首次加载和失败不会显示虚假的零角标，失败在弹层提供重试。查看邀请不改变数量；接受或忽略复用 `InvitationList` 和既有带 CSRF 的响应接口。处理成功刷新邀请和账号信息，不自动切换组织。写入中禁止关闭详情，失败保留错误；处理后没有待处理邀请时隐藏数字。

## 验证

覆盖目录归属、普通用户/组织管理员权限、直接访问受限页、历史返回、分组展开与页面选择、旧链接、工作区切换、响应式分组、手机抽屉和邀请失败/数量更新。旧链接重定向逐一核对查询参数与 hash 原样保留，含空格与 `%25` 等转义序列不被二次编码；设置子页切换断言导航实例不重挂载、选中分组跟随当前页。搜索覆盖文档索引排除 API、真实接口范围、结果高度、键盘滚动和单一焦点，以及资源失败时出现重试而非空态。

浏览器验证使用本地开发版和独立接口测试数据；不等同于真实后端写入或生产验收。桌面展开、图标栏、手机、中英文和明暗主题分别检查。无需运行 verify-be。

构建前运行 `bun run lint:i18n`，使用 TypeScript AST 校验生产源码中静态 `msg` 和 `labelId` 引用在中英文目录中均存在。动态拼接的键继续由对应功能测试覆盖。

文件详情的创建时间使用共享日期格式化器，按当前语言和浏览器时区展示完整日期与分钟。

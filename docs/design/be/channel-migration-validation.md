# 原生渠道迁移验证记录

## 实现边界

渠道直接复用 OMA 进程内的会话事件订阅、历史补读与去重，不再每秒查询历史。渠道仅保存外部消息与 OMA 输入、会话和平台交付的关联，不复制执行日志。公共渠道编排与飞书适配层分离，便于增加其他渠道。

文件收发复用 OMA Files 与会话资源能力；删除渠道自设的附件数量、单文件大小和整批总大小预算，不新增渠道配置。飞书入站读取使用已有的 `storage.max_file_bytes`，图片格式与平台上传限制在飞书适配层处理。出站依据原生文件元数据读取并核对实际长度。

## 已验证

- 普通全仓单测、渠道 race、lint、死代码、复杂度和重复代码检查通过。
- 前端已有功能回归：1856 项通过；构建和格式检查通过。
- 真实飞书收发：单条输入 11 个附件，包括 5 个 26 MiB 文件和 6 个小文件，总计 136,315,006 字节。工具读取全部附件，大小和 SHA-256 与原件一致。
- 同轮产生 12 个输出文件，总计 136,315,029 字节；飞书实际收到 12 条文件消息，全部重新下载核对大小与 SHA-256 一致。完成卡包含工具执行记录。
- 专项应用真实配对批准、撤销与重新批准，真实凭据轮换后的私聊和群聊，固定智能体版本及多资源实际读取已验证。
- 真实正常并发 2、4、8 路均完成；独立旧渠道与原生渠道各 3 个暖样本的正文首显中位数分别为 7.948 秒与 4.414 秒。输出长度不同，这些数据不代表总体吞吐提升或故障隔离验收。

- 资源编辑向导的操作栏遮挡已修复。在 1500×826 浏览器视口中，连续添加两个文件、保存、刷新编辑回显、移除单项与清空均通过；真实飞书触发的沙箱读取了两个正确文件，移除第一项后新会话仅保留第二项。配置最终与原基线一致。

## 尚未完成

- 真实断网、进程强杀、平台回执丢失、运行中 NATS 故障与多实例故障隔离尚未完整验收。
- 多图语义场景仍有模型颜色识别错误；传输字节一致。旧版本因当前 OMA 挂载路径合同不兼容未进入模型阶段，不能据此认定旧版存在相同语义问题。
- 部分补权流程、上传中断恢复和配置权限边界仍待验收。
- 聊天专属记忆、菜单计划、协作、自助应用、报告和旧数据导入按当前范围不实施。

真实平台标识、内部地址、原始消息与文件证据仅保留在本机；验收服务、应用、会话、沙箱和浏览器资源继续保留。

## 合并主分支的迁移编号

主分支的 `00117_skills_management.sql` 保持不变。未合入主分支的渠道迁移顺延为 `00118` 至 `00124`，SQL 内容不变。旧验收 checkout 与其已应用的迁移编号保持原样；不能将新分支直接切换到该数据库启动。保留旧验收数据的升级需先备份，并按迁移文件名称对齐版本登记及补跑技能迁移，不能仅按数字认定两个分支的迁移等价。

## PR 审查后的四项收敛

- 历史响应完整解码；入站归属检查使用 OMA 现有用户输入类型过滤和原生事件 ID 分页游标。仅记住已核对且处理完成的输入位置，重启重新补读，不复制事件历史；实时回复仍消费内部订阅。
- 入站整批附件使用标准临时文件校验，随后流式上传到 OMA Files，不再保留整批字节或复制整份 multipart 请求。飞书 SDK 仍缓冲单个下载文件。临时文件关闭清理，不删除实际平台与会话资源。
- 删除已退出生产路由的外置 bridge 代理链和专属测试。共享 CSRF 与凭据校验保留，原生路由覆盖未认证、工作区隔离、归档禁写及浏览器 CSRF。
- 删除内存产物去重表和无持久回执的发送旁路，交付及测试统一使用已有冻结计划和持久回执。

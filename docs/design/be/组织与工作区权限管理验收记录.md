- 迁移 00060 只增加默认身份标记及组织级唯一索引；歧义默认空间回填原子失败。
- 历史 Default 成员保持原样，角色冲突不参与授权；新组织、seed 不写默认成员，组织成员移除也保留这些历史行。

## 兼容与发布注意

当前没有独立 Admin Key 类型。普通 Workspace Key 不再获得组织管理 API 权限；组织管理要求当前有效 Org Admin 用户会话，工作区成员接口允许目标空间的 Workspace Admin。对外原有响应字段保持兼容。

只能回退到满足新权限合同的兼容版本。保留历史 Default 成员不代表旧授权逻辑可以安全回退。

---
title: "Create a session"
description: "Combine an agent and environment into one stateful task."
api: "POST /v1/sessions?beta=true"
---

Creates a session, its primary thread, and queued environment work. This resource currently requires `beta=true`.

<ParamField query="beta" type="boolean" required>
  Must be `true`.
</ParamField>

<ParamField body="agent" type="string | object" required>
  An agent ID, or `{ "type": "agent", "id": "agent_...", "version": 1 }`.
</ParamField>

<ParamField body="environment_id" type="string" required>
  The ID of an unarchived environment.
</ParamField>

<ParamField body="title" type="string | null">
  Session title.
</ParamField>

<ParamField body="resources" type="array">
  File, GitHub repository, or memory store resources to mount.
</ParamField>

<ParamField body="vault_ids" type="array">
  Vault IDs that the session may use.
</ParamField>

<ParamField body="metadata" type="object">
  Custom key-value metadata.
</ParamField>

```json Request
{
  "agent": {
    "type": "agent",
    "id": "agent_01...",
    "version": 1
  },
  "environment_id": "env_01...",
  "title": "Update the installation guide",
  "resources": [],
  "vault_ids": [],
  "metadata": {
    "source": "docs"
  }
}
```

After creation, the session normally starts as `idle` and its environment work enters the queue. Follow session events or a thread stream for subsequent execution.

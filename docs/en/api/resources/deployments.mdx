---
title: "Deployments and runs"
description: "Manage schedules, manual triggers, and deployment run history."
---

Every request requires:

```http
anthropic-version: 2023-06-01
anthropic-beta: managed-agents-2026-04-01
```

| Method | Path | Purpose |
| --- | --- | --- |
| `POST` / `GET` | `/v1/deployments` | Create / list |
| `GET` / `POST` | `/v1/deployments/{id}` | Retrieve / update |
| `POST` | `/v1/deployments/{id}/archive` | Archive |
| `POST` | `/v1/deployments/{id}/pause` | Pause schedule |
| `POST` | `/v1/deployments/{id}/unpause` | Resume schedule |
| `POST` | `/v1/deployments/{id}/run` | Trigger immediately |
| `GET` | `/v1/deployment_runs` | List runs |
| `GET` | `/v1/deployment_runs/{id}` | Retrieve run |

Creation requires name, fixed agent reference, environment ID, and 1 to 50 initial events. Resources and vault references are resolved before a run creates a session.

Run filters include deployment ID, agent ID, trigger type, status, and time range. A successful run has `session_id`; failure has a structured `error`.

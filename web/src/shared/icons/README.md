# 产品图标

`product-icons.tsx` 使用本项目独立编写的 SVG 基础几何，以模块语义设计图形。绘制不使用第三方图标的路径、轮廓转换或导出文件，不引入图标包、字体、外链或网络请求。

统一规则为 24×24 viewBox、1.5px 描边、圆形端点与连接、`currentColor`。侧栏主项使用 18px，资源子项使用 16px，模块空状态沿用既有尺寸。同一模块的侧栏和页面共用组件；文件夹与文件内容、模块图标与具体操作保持语义区别。

| 入口                             | 图形语义                              |
| -------------------------------- | ------------------------------------- |
| 快速开始 / 智能体 / 会话         | 火箭 / 机器人 / 对话框                |
| 概览 / 部署 / 环境               | 面板 / 包裹 / 服务设备                |
| 资源 / 工作区                    | 打开的资源箱 / 建筑                   |
| 技能 / 文件 / 记忆 / 凭据保险库  | 带星标的手册 / 文件夹 / 大脑 / 保险柜 |
| MCP 服务器 / MCP 隧道 / Webhooks | 插头 / 连接网络 / 事件分发            |
| 模型 / 可观测 / 用量 / 成本      | 芯片 / 波形 / 柱形 / 钱包             |
| 成员 / API 密钥 / 管理 / 文档    | 人物 / 钥匙 / 齿轮 / 书页             |

图标由控件或文字提供可访问名称，装饰 SVG 使用 `aria-hidden`。新增图标继续按产品语义绘制，并在侧栏、模块空状态、明暗主题和折叠状态检查实际效果。

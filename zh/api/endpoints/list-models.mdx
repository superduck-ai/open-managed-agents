---
title: "列出模型"
description: "查询当前 OMA 部署公开的模型和能力。"
api: "GET /v1/models"
---

返回 OMA 当前配置公开的模型列表。部署者可以通过 `anthropic_upstream.model_mappings` 将逻辑模型 ID 映射到上游模型 ID。

## 响应

<ResponseField name="data" type="array">
  模型对象列表。
</ResponseField>

<ResponseField name="data[].id" type="string">
  调用 API 时使用的模型 ID。
</ResponseField>

<ResponseField name="data[].display_name" type="string">
  控制台中显示的模型名称。
</ResponseField>

<ResponseField name="data[].max_input_tokens" type="integer">
  模型声明的最大输入 token 数。
</ResponseField>

<ResponseField name="data[].max_tokens" type="integer">
  模型声明的最大输出 token 数。
</ResponseField>

<ResponseField name="data[].capabilities" type="object">
  thinking、图像、PDF、结构化输出、代码执行等能力标记。
</ResponseField>

```json Response
{
  "data": [
    {
      "type": "model",
      "id": "claude-sonnet-4-6",
      "display_name": "Claude Sonnet 4.6",
      "max_input_tokens": 1000000,
      "max_tokens": 128000,
      "capabilities": {
        "code_execution": {"supported": true},
        "image_input": {"supported": true}
      }
    }
  ],
  "has_more": false,
  "first_id": "claude-sonnet-4-6",
  "last_id": "claude-sonnet-4-6"
}
```

您可以将 GitHub 代码仓库挂载到会话沙箱中，并连接到 GitHub MCP 以创建拉取请求。

GitHub 代码仓库会被缓存，因此使用相同代码仓库的后续会话启动速度会更快。

<Note>
  托管智能体 API 请求需要 `managed-agents-2026-04-01` Beta 请求头，但记忆存储端点除外，它们使用 `agent-memory-2026-07-22`。SDK 会自动设置正确的 Beta 请求头。请参阅[Beta 请求头](/docs/zh/api/versioning-beta)。
</Note>

## GitHub MCP 和会话资源

首先，创建一个声明 GitHub MCP 服务器的智能体。智能体定义中包含服务器 URL，但不包含身份验证令牌：

  ```bash cURL
    -H "anthropic-beta: managed-agents-2026-04-01" \

    --data @- <<JSON | jq -r '.id'
  ```

`resources[].authorization_token` 用于对代码仓库克隆操作进行身份验证，不会在 API 响应中回显。

挂载代码仓库时，还会加载存储在其根目录 `.claude/skills` 文件夹中的所有技能。技能在每个会话中仅发现一次，基于会话启动时检出的代码仓库状态。请参阅[从 GitHub 代码仓库加载技能](/docs/zh/skills#load-skills-from-a-github-repository)。

## 令牌权限

提供 GitHub 令牌时，请使用最低所需权限：

| 操作       | 所需作用域                     |
| -------- | ------------------------- |
| 克隆私有仓库   | `repo`                    |
| 创建 PR    | `repo`                    |
| 读取 issue | `repo`（私有）或 `public_repo` |
| 创建 issue | `repo`（私有）或 `public_repo` |

<Warning>
  请使用具有最低所需权限的细粒度个人访问令牌。避免使用对您的 GitHub 账户具有广泛访问权限的令牌。
</Warning>

## 管理运行中会话的代码仓库

会话创建后，您可以列出其代码仓库资源并轮换其授权令牌。每个资源都有一个在会话创建时（或通过 `resources.list`）返回的 `id`，您可以使用它进行更新。代码仓库在会话的整个生命周期内保持挂载状态；如需更改挂载的代码仓库，请创建新会话。

<CodeGroup>
  ```bash cURL
  # 列出会话上的资源
  repo_resource_id=$(curl -fsS "http://localhost:38080/v1/sessions/$session_id/resources" \
    -H "x-api-key: $OMA_API_KEY" \
    -H "anthropic-version: 2023-06-01" \
    -H "anthropic-beta: managed-agents-2026-04-01" \
    -H "content-type: application/json" | jq -r '.data[0].id')
  echo "$repo_resource_id"  # "sesrsc_01ABC..."

  # 轮换授权令牌
  curl -fsS "http://localhost:38080/v1/sessions/$session_id/resources/$repo_resource_id" \
  # ...
    -o /dev/null \
    --data @- <<JSON
  {
    "authorization_token": "ghp_your_new_github_token"
  }
  JSON
  ```

  ```bash CLI
  # 列出会话上的资源
  ant beta:sessions:resources list --session-id "$SESSION_ID"

  # 轮换特定资源上的授权令牌
  ant beta:sessions:resources update \
    --session-id "$SESSION_ID" \
    --resource-id "$RESOURCE_ID" \
    --authorization-token "ghp_your_new_github_token"
  ```


## 创建拉取请求

借助 GitHub MCP 服务器，智能体可以创建分支、提交更改并推送它们：

<CodeGroup>
  ```bash cURL
  curl -fsS "http://localhost:38080/v1/sessions/$session_id/events" \
    -H "x-api-key: $OMA_API_KEY" \
    -H "anthropic-version: 2023-06-01" \
    -H "anthropic-beta: managed-agents-2026-04-01" \
    -H "content-type: application/json" \
    -o /dev/null \
    --data @- <<JSON
  {
    "events": [
      {
        "type": "user.message",
        "content": [
          {
            "type": "text",
            "text": "Fix the type error in src/utils.ts, commit it to a new branch, and push it."
          }
        ]
      }
    ]
  }
  JSON
  ```

  ```bash CLI
  ant beta:sessions:events send \
    --session-id "$SESSION_ID" \
    > /dev/null <<'EOF'
  events:
    - type: user.message
  ```

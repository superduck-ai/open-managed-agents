# 会话预算与请求计费

会话和部署可以在创建时设置 USD 预算，金额使用整数字符串表示美分。部署创建的会话继承预算；会话预算修改必须高于累计费用，移除后不能重新添加。带预算的最终 Agent 快照必须引用已配置价格的模型。

模型费用由模型代理完成每次请求时生成，写入 `span.model_request_end.billing`；不再从 Worker 的回合汇总结果合成计费事件，避免重复计费。预算查询优先读取主分支的 `model_usage` 协议，同时兼容旧事件的 `usage`；外置事件摘要保留计量字段。输入、输出、缓存读写分别按 `billing.model_prices` 计算，每次请求四舍五入到美分。模型请求起止事件用于累计活跃时间。

事件持久化后汇总费用，达到预算时记录 `budget_reached_at`，追加 `session.usage` 和带 `budget_reached` 原因的空闲事件。输入边界仅接受工具结算和中断事件。此机制为请求完成后的检查，不保证当前请求费用不超过预算。

迁移 `00072_session_budget.sql` 添加预算字段，避开主分支已经使用的迁移编号。预算字段参与 `session.updated` 变化检测，沿用主分支的事务状态投影和 Worker 清理逻辑。

验证包括计费计算、代理请求计费映射、预算输入与事件限制单测，以及隔离依赖环境中的 Go 测试和聊天 roundtrip。真实云沙箱和真实模型凭据的验证需单独执行，脚本上游不能替代该验收。

## 控制台预算状态与国际化

预算界面提供中文和英文词条，金额使用当前语言的 USD 格式，动态金额通过 ICU 参数插值。后端预算错误在界面边界转换为本地化文案，API 错误合同保持不变。

会话详情收到模型结束、用量、空闲或预算更新事件时，重新读取会话的权威预算和累计费用；发送消息被预算门禁拒绝时也触发刷新。已确认触顶时统一显示可调整或移除预算的警告，并禁止继续发送普通消息，不再同时显示原始协议错误。该同步不从局部或分页事件列表自行推算累计费用，预算修改仍以服务端响应为准。

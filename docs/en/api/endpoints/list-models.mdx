---
title: "List models"
description: "Inspect model IDs exposed by this workspace."
api: "GET /v1/models"
---

Returns the model IDs configured for the current workspace. IDs are used unchanged in API calls.

## Response

<ResponseField name="data" type="array">
  A list of model objects.
</ResponseField>

<ResponseField name="data[].id" type="string">
  The model ID to use in API calls.
</ResponseField>

```json Response
{
  "data": [
    {
      "type": "model",
      "id": "kimi-k2.5"
    }
  ]
}
```

Returns `503` when the workspace has no configured LLM Provider. Clients can identify this condition using the stable `error.code` value, independently of the human-readable message:

```json 503 Response
{
  "error": {
    "type": "api_error",
    "code": "workspace_llm_provider_not_configured",
    "message": "This workspace has no LLM provider configured"
  }
}
```

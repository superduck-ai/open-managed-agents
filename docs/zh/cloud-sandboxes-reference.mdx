<Note>
  OMA 不绑定单一托管镜像。本页列出的运行时能力取决于部署者配置的 E2B 或兼容环境运行器；上线前请在目标镜像中验证软件包和容量。
</Note>

云沙盒作为隔离的 Linux 容器运行在 OMA 管理的基础设施上。它们预装了一套全面的编程语言、数据库和实用工具。智能体可以立即使用这些工具，无需任何安装步骤。

这些规格适用于 `cloud` 环境。自托管沙盒运行在您的基础设施上，使用您的 worker 所提供的任何内容。

<Note>
  托管智能体 API 请求需要 `managed-agents-2026-04-01` Beta 请求头，但记忆存储端点除外，它们使用 `agent-memory-2026-07-22`。SDK 会自动设置正确的 Beta 请求头。请参阅[Beta 请求头](/docs/zh/api/versioning-beta)。
</Note>

| Go      | 1.22+   | go modules      |
| Rust    | 1.77+   | cargo           |
| Java    | 21+     | maven, gradle   |

| C/C++   | GCC 13+ | make, cmake     |

## 数据库

| 数据库            | 描述                    |
| -------------- | --------------------- |
| SQLite         | 预装，可立即使用              |
| PostgreSQL 客户端 | 用于连接外部数据库的 `psql` 客户端 |
| Redis 客户端      | 用于连接外部实例的 `redis-cli` |

<Note>
  数据库服务器（如 PostgreSQL 和 Redis）默认不在沙盒中运行。沙盒包含用于连接外部数据库实例的客户端工具。SQLite 完全可用于本地使用。
</Note>

## 实用工具

### 系统工具

* `git` - 版本控制
* `curl`、`wget` - HTTP 客户端
* `jq` - JSON 处理
* `tar`、`zip`、`unzip` - 归档工具
* `ssh`、`scp` - 远程访问（需要允许目标主机的网络模式）
* `tmux`、`screen` - 终端多路复用器

### 开发工具

* `make`、`cmake` - 构建系统
* `docker` - 容器管理（可用性有限）
* `ripgrep`（`rg`）- 快速文件搜索
* `tree` - 目录可视化
* `htop` - 进程监控

### 文本处理

* `sed`、`awk`、`grep` - 流编辑器
* `vim`、`nano` - 文本编辑器
* `diff`、`patch` - 文件比较

## 沙盒规格

| 属性   | 值                                                                                                                                                        |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 操作系统 | Ubuntu 22.04 LTS                                                                                                                                         |
| 架构   | x86\_64 (amd64)                                                                                                                                          |
| 内存   | 最高 8 GB                                                                                                                                                  |
| 磁盘空间 | 最高 10 GB                                                                                                                                                 |
| 网络   | 通过 API 创建的环境默认使用 [`unrestricted` 网络](/docs/zh/environments#networking)；通过 OMA 控制台配置的沙盒默认使用 `limited` |

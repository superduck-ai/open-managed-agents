# 工作台布局与状态样式

工作台继续复用现有 Tabs、DropdownMenu、Button 和抽屉组件，提示编辑、模型执行、保存与附件协议保持原样。

## 响应式布局

1024px 以下使用单列：提示编辑区在前，响应区在后，页面按内容纵向滚动。模式切换回到正常文档流，操作区取消桌面定位所需的顶部空白。工具栏按内容换行，同样适用于桌面较窄的编辑列。

1024px 及以上保留现有双栏。不能只通过文档没有横向滚动判断页面可用：需要核对编辑区本身的宽度、内部滚动和文字裁剪。原双栏在 390px 下给编辑区仅剩约 14px，属于内容不可用，即使 documentWidth 仍为 390px 也不能通过。

## 状态颜色与焦点

系统提示展开标题和悬停图标使用 foreground，次要说明使用 muted-foreground。附件触发器的展开、悬停和焦点沿用中性 accent 表面与 foreground，不突然切换成硬编码黑底白字。新增提示图标的暖色采用已有 Radix Orange 11，结构按钮边界使用 0.5px。

系统提示折叠入口使用共享 0.5px 内侧焦点，删除局部重复的 2px 外轮廓。不能同时绘制多层焦点来增强存在感。展开、关闭和菜单键盘行为不因样式调整改变。

## 验收范围

系统提示键盘焦点、展开及附件菜单覆盖桌面明暗与 390px 浅色的真实前后截图。另测 320、390、900、1024、1280px 下的编辑区和工具栏 clientWidth / scrollWidth，确认内容可读且没有内部横向裁剪。

仅展开和关闭既有控件，不修改提示正文、不保存、不运行模型或上传附件。带变量的内容、已有附件与 Evaluate 展示现已有隔离组件对照；真实上传、拖放和评估执行仍需独立验收，不能用空提示或隔离样本代替。

## 共用弹窗退出及输入焦点

工作台 Dialog 包装器复用共享退出状态：普通关闭先完成 Base UI 退场，再通知父级清除打开状态。代码、附件地址、提示词改进、分享、生成输入与重命名的关闭按钮和取消统一使用 primitive Close。删除及生成器关闭确认的取消同样保留退场。标题栏结构边界为0.5px，默认阴影使用语义令牌。

附件地址、生成任务和重命名输入通过 Base UI initialFocus 指定初始焦点，避免 React autoFocus 抢先改变打开入口记录；键盘取消后回到入口。改进、分享和删除处理中禁止关闭，改进输入与思考选项同步禁用。分享日期显式使用应用语言，不由浏览器默认语言决定。

生成器运行中请求关闭先进入原有二次确认，受控 open 由页面决定，不提前退场。取消二次确认后保留生成器和当前输出。确认停止时立即中止请求并关闭两层受控弹窗，内容保留至退出完成后再清理；空输出的中止回调不能在退出中切回任务步骤。两层 Root 常驻、确认文案保留，退出结束只清理一次，焦点回到打开入口。新一轮打开会重置草稿；退出回调需确认当前仍关闭，避免清空已重新打开的内容。没有为动画延迟模型、保存、分享或删除请求。

普通弹窗和生成器复用 DialogSurface 显示层，分别保留自身关闭控制，不再在通用包装器中设置生成器专用的 beforeClose 分支。已有部分输出和空输出两组隔离前后对照，正常180ms、减少动态效果0ms；实际中止在本机AbortController及组件/页面模拟测试中验证，未执行真实付费模型链路。

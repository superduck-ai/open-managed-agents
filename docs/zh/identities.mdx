**身份**表示在工作区中执行智能体任务的业务主体。渠道根据固定绑定或聊天范围配对选出这个身份，OMA 将会话和使用记录归到该身份下。您可以在控制台的执行身份页面查看状态，也可以通过[身份 API](/docs/zh/api/identities/list-identities)查询身份、使用统计和关联智能体。

| 资源 | 用途 |
| --- | --- |
| 身份 | 记录执行归属、启用状态以及与智能体相关的配置 |
| 范围配对 | 把某个渠道的私聊用户或群绑定到一个身份和智能体 |
| 会话 | 保存一次持续对话的执行状态、事件和工具结果 |
| 密钥库 | 保存外部服务凭据，并在工具调用时按会话范围使用 |

## 飞书个人身份

对于启用了[私聊自助配对](/docs/zh/message-channels)的渠道，首条获准的私聊消息会触发身份绑定。OMA 按同一工作区、同一飞书应用、同一发送者复用个人身份。解除配对后重新接入时，仍能找回原个人身份和密钥库。

固定身份渠道也可以使用个人工具授权。会话归属由固定身份决定，个人凭据由实际发起工具调用的飞书用户决定。

## 个人和共享凭据

- **个人凭据**用于当前操作者的私聊。当需要授权外部服务时，OMA 会核验原消息发送者，再将授权保存到其个人密钥库。
- **共享凭据**来自管理员显式挂载的密钥库，包括渠道挂载和该身份对当前智能体的有效挂载。对同一环境变量或 MCP 连接，匹配的共享凭据优先。
- **群聊凭据**来自有效的共享挂载。成员在私聊中取得的个人授权适用于该成员的私聊。

配置共享密钥库前，请确认挂载范围中的用户均可使用该凭据代表的权限。需要下游服务按人授权时，通过私聊使用个人密钥库。

## 停用与解除配对

| 操作 | 影响 |
| --- | --- |
| 停用身份 | 阻止新的任务受理，已经受理的任务可继续收尾 |
| 重新启用 | 恢复该身份的新任务受理。此前因停用被拦住的消息需要重发 |
| 解除配对 | 解除当前聊天范围和执行目标的绑定。仍获准的私聊用户可重新建立配对 |

详细请求字段和接口见[身份 API](/docs/zh/api/identities/list-identities)。

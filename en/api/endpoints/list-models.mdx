---
title: "List models"
description: "Inspect models and capabilities exposed by this OMA deployment."
api: "GET /v1/models"
---

Returns the model catalog exposed by the current OMA configuration. Operators can use `anthropic_upstream.model_mappings` to map logical model IDs to upstream IDs.

## Response

<ResponseField name="data" type="array">
  A list of model objects.
</ResponseField>

<ResponseField name="data[].id" type="string">
  The model ID to use in API calls.
</ResponseField>

<ResponseField name="data[].display_name" type="string">
  The model name displayed in the console.
</ResponseField>

<ResponseField name="data[].max_input_tokens" type="integer">
  Declared maximum input tokens.
</ResponseField>

<ResponseField name="data[].max_tokens" type="integer">
  Declared maximum output tokens.
</ResponseField>

<ResponseField name="data[].capabilities" type="object">
  Capability flags for thinking, image and PDF input, structured output, code execution, and more.
</ResponseField>

```json Response
{
  "data": [
    {
      "type": "model",
      "id": "claude-sonnet-4-6",
      "display_name": "Claude Sonnet 4.6",
      "max_input_tokens": 1000000,
      "max_tokens": 128000,
      "capabilities": {

        "image_input": {"supported": true}
      }
    }
  ],
  "has_more": false,
  "first_id": "claude-sonnet-4-6",
  "last_id": "claude-sonnet-4-6"
}
```

# 前端共性问题与页面问题

本轮依据 [设计规范](design-system.md) 和 [视觉参考研究](claude-har-design-reference.md) 统一共享规则，再处理页面专属布局。同步主线前的视觉验收结论及提交前集成边界见 [49 组视图验收表](eleven-requirements-audit-2026-10-26.md)，不以共享主题接入或截图数量代替逐项判断。

## 问题归属

| 类型 | 修复位置 | 判断原则 |
| --- | --- | --- |
| 共享默认问题 | 主题令牌、shared/ui | 相同语义由共享组件统一，避免各页面重复修复 |
| 共性接入问题 | 功能组件及局部样式 | 删除冲突覆盖，遵循共享合同，不叠加更强的全局 CSS |
| 页面专属问题 | 对应 feature | 按业务任务处理分组、优先级、长内容和必要说明 |

## 共享规则与修复

| 范围 | 当前实现 | 主要入口 |
| --- | --- | --- |
| 配色 | 官方 Radix 明暗及 alpha 色阶映射语义令牌；保留轻暖表面和软件包、权限识别色 | styles/palette.css、styles/foundation.css |
| 边界与焦点 | 结构边界 0.5px；复合字段由一个外壳负责完整中性焦点；错误、选中与 hover 分开表达 | shared/ui、AgentConfigEditor |
| 选择器 | 所有表单值选择支持搜索；下方展开、起点对齐；单选后关闭，多选保持搜索；关闭后清空临时查询 | Select、Combobox、Popover、Command |
| 选择器几何 | 外角 12px、选项 8px、gutter 4px，避免分组重复内边距；细滚动条与触发器宽度受视口约束 | shared/ui/select.tsx、command.tsx |
| 字号 | 最小 12px；单页优先三档、最多四档；通过字重、颜色和间距补充分级 | ResourcePageHeader、Dialog、功能组件 |
| 动效 | 菜单约 150ms、弹窗 180ms、侧栏和折叠 220ms，主要使用 ease-out；减少动态效果时简化过渡和加载动画 | styles/motion.css、shared/ui、useReducedMotion |
| 退出生命周期 | 关闭后保留内容直到 primitive 完成退出，再清理选中对象或刷新父级；保存中拒绝重复操作和意外关闭 | useDialogDismissal、功能弹窗 |
| 表格与空态 | 非空表格内部滚动；空、加载、错误和无匹配状态不继承无意义列宽、表头和分页 | ResourceTable、资源目录 |
| 长内容 | 可收缩网格与 flex 子项，连续长文本换行；短屏正文滚动，标题、关闭和操作可达 | Dialog、Sheet、功能详情 |
| 文案 | 去掉中点分隔、重复说明及装饰眉题；保留权限、格式、一次性披露及不可逆后果 | shared/i18n、功能组件 |

## 页面专属修复

| 模块 | 调整重点 |
| --- | --- |
| 环境 | 保留圆润双栏布局，统一字段对齐和操作条；恢复软件包类别识别色，修正预览短屏边界 |
| 智能体 | 模板和权限编辑不再裁切边界；详情、快速查看和版本选择沿用共享层级 |
| 会话 | 主对话与检查器优先级清晰，资源组合字段不溢出；长路径、事件和工具输出内部滚动 |
| 工作台 | 模型、工具、变量和历史侧栏在短屏可达，保留进出过渡；示例和评估表格处理长内容、加载与重试 |
| 模型与 Provider | 模型名称、ID、能力与操作分级；失败保留草稿，保存和删除成功后的退出不被父级刷新打断 |
| 文件与技能 | 空态、错误和列表清晰区分；上传失败保留有效选择供重试，退出完成后再切换结果 |
| 设置与成员 | 连续字段减少重复卡片；成员范围和权限说明紧邻操作；一次性密钥在退出期间保留内容 |
| MCP、记忆存储与保险库 | 加载和失败保留关闭与重试；长名称和凭据列表不挤出操作，目录错误不冒充空数据 |
| 首页与未接入入口 | 首页以现有 Agent、会话和模型入口组织；未接入页面明确当前能力，不展示模拟余额或统计 |

## 验收边界

同步主线前，49 组视图按 11 项要求逐项记录，其中 45 组真实页面、4 组实际组件隔离。结论仅适用于记录中的视觉和交互状态；原始截图及采集过程留在本地，不随代码发布。

全视图原生 200% 缩放、全像素对比度认证及真实模型、权限和资源写入链路不在本次结论中。设计规范规定的目标不等于已经完成这些验证。后续改动应针对受影响页面和状态重新验收，而不是沿用本轮通过标记。

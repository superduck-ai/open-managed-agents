OMA 提供以资源为中心的 HTTP API，并尽量兼容 Anthropic SDK 的请求、响应和错误外观。默认本地地址为：

```text
http://localhost:38080
```

所有公开资源接口都位于 `/v1`。控制台使用的 `/api`、`/auth` 和 `/web-api` 路由不是公共 SDK 合同。

## 第一个请求

```bash
curl http://localhost:38080/v1/models \
  -H 'Authorization: Bearer sk-ant-local-default'
```

也可以使用 `X-Api-Key`：

```bash
curl http://localhost:38080/v1/models \
  -H 'X-Api-Key: sk-ant-local-default'
```

## 通用请求头

| 请求头 | 必需性 | 说明 |
| --- | --- | --- |
| `Authorization: Bearer <key>` | 二选一 | Bearer API key |
| `X-Api-Key: <key>` | 二选一 | Anthropic SDK 常用 API key 请求头 |
| `Content-Type: application/json` | JSON 请求必需 | 请求体编码 |
| `anthropic-version: 2023-06-01` | SDK 兼容请求建议 | API 兼容版本 |
| `anthropic-beta` | 视资源而定 | 部分 beta 资源要求特定值 |

<Warning>
  OMA 没有统一的 beta 请求模板。部分资源要求 `?beta=true`，部分资源还检查自己的 `anthropic-beta` 值。请以资源页面为准。
</Warning>

## 响应和追踪

成功响应使用 JSON。服务会在响应头和错误体中返回 `request-id`，用于关联服务端日志。

```json
{
  "type": "error",
  "request_id": "req_...",
  "error": {
    "type": "invalid_request_error",
    "message": "..."
  }
}
```

---
title: "List agents"
description: "Page through agents in the current workspace."
api: "GET /v1/agents?beta=true"
---

Lists agents visible in the current workspace. This resource currently requires `beta=true`.

<ParamField query="beta" type="boolean" required>
  Must be `true`.
</ParamField>

<ParamField query="limit" type="integer">
  Maximum number of results. The maximum is 100.
</ParamField>

<ParamField query="page" type="string">
  An opaque cursor returned by the previous page.
</ParamField>

<ParamField query="include_archived" type="boolean">
  Include archived agents. They are excluded by default.
</ParamField>

<ParamField query="created_at[gte]" type="string">
  Return agents created at or after this RFC 3339 timestamp.
</ParamField>

<ParamField query="created_at[lte]" type="string">
  Return agents created at or before this RFC 3339 timestamp.
</ParamField>

```bash
curl 'http://localhost:38080/v1/agents?beta=true&limit=20' \
  -H 'Authorization: Bearer sk-ant-local-default' \
  -H 'anthropic-version: 2023-06-01'
```

A `null` `next_page` in the response means you reached the final page.

# 工作区选择器

选择器展示服务端返回的可访问工作区，保留现有切换行为和 Default 展示名称。

具有 `canManageWorkspaces` 权限时，列表底部依次显示“创建工作区”和“管理工作区”。创建入口打开现有创建对话框；管理入口通过现有客户端导航进入 `/settings/workspaces`，同时关闭菜单。两个操作入口共用组织管理权限，无权限时均不显示。

验收同时覆盖空间列表、切换、创建和管理入口；不能只验证列表与切换便认为选择器已完整对齐。组件回归覆盖无权限时隐藏两个操作，以及有权限时管理链接、客户端导航和菜单关闭。

创建工作区后重新获取活动工作区列表，用服务端返回的有效角色安装新作用域，避免直接使用创建响应中的缺失权限。创建请求提交后若组织或工作区作用域已切换，返回创建成功结果但不覆盖新作用域；刷新列表缺少新建项时使用创建响应补齐，避免选中空工作区。列表优先保留服务端有效权限，创建响应缺失权限时按现有规则降级。刷新列表时重新选择仍可访问的当前空间；当前空间已归档或失去访问权限时，沿用 Default 回退规则并同步导航、请求上下文与偏好。归档列表仅由设置页单独查询，不进入工作区选择器。

账号菜单与工作区成员表按服务端有效角色展示“用户 / 管理员”，中英文分别为 User / Admin 和用户 / 管理员。组织成员编辑与邀请也只提供这两个选项。未知或缺失角色的展示降级为用户，不能暗示管理员权限；实际可见入口仍由服务端权限控制。切换 MCP Tunnel 列表或详情时，进入目标工作区列表，丢弃旧 Tunnel ID 和查询参数。

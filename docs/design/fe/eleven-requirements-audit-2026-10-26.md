## 各视图的判断依据

### 创建智能体 (agent-create)

起点、通用配置和可选区块按任务顺序组织；双列字段在窄屏单列，底部操作独立。 保留模板区别、字段约束与权限语义；没有重复页头介绍。

### 智能体详情 (agent-detail)

标题、ID、版本和内容页签层级明确；配置区使用留白和必要的代码表面。 保留资源名称、配置正文与空态，不翻译用户内容；版本选择支持搜索。

### 智能体列表 (agents)

标题与创建入口同一工具栏；筛选集中，表格名称和ID分级。 当前列表保留模型、创建与更新时间，不加装饰分区。

### API 密钥 (api-keys)

密钥表格按名称、创建者、时间与操作对齐；窄屏表格内部横滚。 保留密钥归属与生命周期说明，这是权限后果；不生成真实密钥验收。

### 批处理 (batches)

空列表收敛为工作区空态，隐藏无数据时无意义的表头与分页。 未接入创建入口时不提供模拟操作。

### 账单 (billing)

账单采用单一未接入状态，不显示假余额或限额。 标题和当前能力状态分别承担导航与可用性说明。

### 缓存 (caching)

缓存统计未接入，保持简洁空态与文档入口。 没有空图表、模拟数据或多重卡片。

### Claude Code 设置 (claude-code-settings)

未接入状态只保留必要说明和相关成员入口。 产品名保留，动作名称与入口目的对应。

### Claude Code 用量 (claude-code-usage)

用量未接入，当前状态清晰且没有装饰表格。 不以虚构指标填满空白。

### 成本 (cost)

成本未接入，采用单一状态，不展示伪造的费用。 不在标题上方添加分类眉题。

### 概览 (dashboard)

Agent、会话、模型为首要入口；工作区资源随后排列。 卡片短说明用于区分目的，资源名称不再附加重复解释。

### 部署详情 (deployment-detail)

概览与运行记录区分明确，详情小标题16px；窄表格内部滚动。 覆盖成功、运行中、失败、空记录与错误；仅隔离实际组件。

### 部署列表 (deployments)

筛选器与创建入口集中；空态明确，详情与编辑沿用共享资源组件。 保留Agent、环境和调度约束；没有重复嵌套表单外框。

### Dreaming (dreaming)

当前功能未接入，只呈现真实能力状态。 不把未实现功能的外观记作业务链路通过。

### 动态设置七个分区 (dynamic-settings)

逐一复核profile、appearance、organization、llm、members、workspaces、keys七个分区。 只读资料、语言/主题、配置与成员管理各自使用适合的表单或目录层级。

### 环境创建与详情 (environment-detail-and-create)

保留原有圆润双列布局，网络访问、软件包、元数据与队列有明确顺序。 网络格式、安装时机和元数据不会交给Agent等说明属于必要约束。

### 环境列表 (environments)

表头、状态筛选与名称列对齐，操作不挤占名称；保留软件包识别色。 创建与编辑复用当前环境表单，不改网络策略。

### 文件 (files)

文件名称、类型元信息、大小与时间分级；下载操作位置统一。 已等待真实文件数据加载完成，首轮加载图不当作最终列表证据。

### 组织邀请 (invites)

邀请组织、角色、有效期与接受/拒绝动作形成清晰顺序。 退出和稍后处理属于当前决策场景所需动作；当前待处理邀请为隔离样本。

### 登录 (login)

一个登录表面，邮箱和验证码步骤分开，没有嵌套表单。 保留验证码送达方式与错误恢复，未发送真实验证码或退出当前账号。

### 日志 (logs)

请求日志未接入，当前页保持明确状态。 没有装饰性日志样本或多余分类。

### 创建 MCP 服务器 (mcp-create)

紧凑单层创建弹窗，名称、URL、操作按常见表单顺序对齐。 保留快照复制语义与HTTP/HTTPS限制，防止误解配置关联方式。

### MCP 服务器详情 (mcp-detail)

当前本机已有MCP记录，补充真实侧栏明暗复核；长名称与错误另用隔离样本。 地址、配置和生命周期分区，复制、关闭和操作可达。

### MCP 服务器列表 (mcp-list)

名称/Endpoint搜索、创建与行操作统一，空与加载状态沿用资源表格。 搜索目标使用既有技术术语，不增加提示段落。

### 记忆存储详情 (memory-detail)

树与正文分区清晰；长路径不挤占菜单、复制和编辑。 错误与空目录有区别，内容预览保留用户文本。

### 记忆存储列表 (memory-stores)

资源目录统一筛选与列对齐，活跃状态使用语义色。 创建、详情与编辑入口不添加额外选择步骤。

### LLM 模型 (models)

Provider导航、模型搜索和模型正文分层；别名/ID仅在不同内容时并列。 保留能力、发现和错误信息，隐藏真实凭据；没有模型执行验收。

### 可观测性 (observability)

当前真实页为未启用状态；图表/筛选依赖已有组件样本与源审查。 保留开启可观测性的必要前提，不用空图表冒充已接入。

### 组织设置 (organization)

组织字段按两列网格排列，权限开关与后果说明紧邻。 权限后果属于必要说明；国家使用统一可搜索选择器。

### 组织成员 (organization-members)

成员目录按名称、邮箱、角色及操作对齐；邀请与角色选择复用共享组件。 角色和错误均本地化；没有发送邀请或更改真实成员权限。

### Playground (playground)

未接入状态将工作台作为可用入口。 不提供不能执行的模拟聊天或模型选择。

### 快速开始 (quickstart)

### 速率限制 (rate-limits)

未接入状态明确，不显示虚假的速率数值。 没有无意义的表格和过度说明。

### 已停用的控制台页面 (retired-console)

只保留页面停用标题与返回应用，移除重复解释。 未改停用路由及返回目的地。

### 已停用的设置页面 (retired-settings)

只保留页面停用标题与组织设置入口，移除重复解释。 复用同一个停用组件，不维护两套文案。

### 会话详情 (session-detail)

时间轴、对话和检查器层级分明；资源/事件/工具/线程等内容复用既有面板。 区分用户内容与应用文案；35处默认边界清理包含该页1px顶部线。

### 会话列表 (sessions)

会话目录集中时间、Agent、部署和状态筛选，ID与标题分级。 状态、用量和操作保留；不通过真实消息或模型调用验证样式。

### 创建技能 (skill-create)

### 技能详情 (skill-detail)

### 技能列表 (skills)

技能名称、来源、版本与时间分级，创建入口与其他资源页一致。 初始空态和无匹配结果区分，用户技能名称保持原文。

### 标签 (tags)

未接入状态简洁且与真实能力一致。 没有用装饰标签或英文眉题伪装为可用配置。

### MCP 隧道详情 (tunnel-detail)

### MCP 隧道列表 (tunnels)

### 用量 (usage)

未接入状态明确且不展示假用量。 保留标题与状态，避免额外装饰层级。

### 凭据保险库详情 (vault-detail)

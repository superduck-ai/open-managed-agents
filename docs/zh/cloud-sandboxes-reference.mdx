云环境使用部署者配置的 E2B 或兼容运行器。实际镜像、工具版本和资源规格由部署决定；自托管环境则使用自有 Worker 提供的环境。

下面的清单参考 [managed-agent-sandbox 的 main 分支](https://github.com/superduck-ai/managed-agent-sandbox/tree/811f3db0a66282ec69b90983a8af429b970bd961)，对应提交 `811f3db0`。它描述该版本的镜像构建配方，不表示每个 OMA 部署都已使用该镜像。请向部署者确认当前模板和镜像版本。

## 基础运行时

此版本基于 Ubuntu 24.04，构建架构包括 `linux/amd64` 和 `linux/arm64`。基础运行时包含以下软件：

| 类别 | 工具和版本 |
| --- | --- |
| 编程语言 | Python 3.13.14、Node.js 24.18.0、Go 1.26.5、Java 25.0.3、PHP 8.5.8、Ruby 3.4.10、Bun 1.3.14、Rust 1.97.0、GCC/G++ 14.2.0 |
| 包管理和构建 | pip、uv、npm、Yarn、pnpm、Cargo、RubyGems、Bundler、Composer、Maven、Gradle、make、CMake |
| 数据库 | SQLite、PostgreSQL 客户端 `psql`、Redis 客户端 `redis-cli` |
| 命令行 | Git、curl、wget、jq、ripgrep、SSH 客户端、tar、zip、unzip、tmux、screen、vim、nano、tree、htop |
| 其他 | Docker CLI、Claude Code；使用 Docker 还需要可访问的 Docker 服务。 |

`psql` 和 `redis-cli` 是连接外部服务的客户端，并不意味着沙箱内启动了 PostgreSQL 或 Redis 服务。连接外部服务还受环境网络策略和目标服务配置限制。

## 文档、数据和多媒体工具

该仓库的默认构建最终阶段 `toolkit` 在基础运行时之上安装：

| 用途 | 工具 |
| --- | --- |
| 文档 | LibreOffice、Poppler、qpdf、Pandoc、Typst；Python 的 `python-docx`、`python-pptx`、`openpyxl`、`pypdf`、`pdfplumber`、`reportlab` |
| 数据和图表 | `pandas`、`numpy`、`matplotlib`、`xlsxwriter` |
| 图形和浏览器 | Graphviz、PlantUML、D2、Mermaid CLI、Playwright 和 Chromium Headless Shell |
| 图像、音视频与文字识别 | ImageMagick、FFmpeg、SoX、Tesseract（中文简体和英文）、eSpeak NG、faster-whisper 和 Whisper Small 模型 |
| 其他 | GitHub CLI (`gh`) |

如果部署使用基础 `runtime` 阶段、旧版本或自定义镜像，以上 toolkit 工具可能不存在。软件版本以镜像仓库中的 [`versions.env`](https://github.com/superduck-ai/managed-agent-sandbox/blob/811f3db0a66282ec69b90983a8af429b970bd961/versions.env) 和锁文件为准。

## 查看当前环境

在会话沙箱中运行以下命令，检查当前操作系统、架构和常用工具：

```bash
cat /etc/os-release
uname -m
python3 --version
node --version
go version
for tool in libreoffice pdftotext tesseract ffmpeg dot mmdc; do
  command -v "$tool" || echo "$tool: 未安装"
done
```

CPU、内存、磁盘、网络模式及软件包准备由[环境配置](/docs/zh/environments)和部署者设置决定。可在沙箱中使用 `nproc`、`free -h` 和 `df -h` 查看当前可见资源；这不代表其他环境具有相同规格。

## 空闲与恢复

会话空闲时，云沙箱可能根据部署配置被回收。后续输入可以触发重新创建沙箱，但系统不对整个沙箱做检查点：本地工作目录、临时文件、后台进程和临时安装的软件可能丢失。会话历史、已提交的持久文件以及重新挂载的资源有各自的生命周期。将需要交付的文件写入 `/mnt/session/outputs/`，并通过[文件页面](/docs/zh/files)查看和下载。

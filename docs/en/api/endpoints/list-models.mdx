---
title: "List models"
description: "Inspect model IDs exposed by this workspace."
api: "GET /v1/models"
---

Returns the model IDs configured for the current workspace. IDs are used unchanged in API calls.

## Response

<ResponseField name="data" type="array">
  A list of model objects.
</ResponseField>

<ResponseField name="data[].id" type="string">
  The model ID to use in API calls.
</ResponseField>

<ResponseField name="data[].display_name" type="string">
  The configured model ID, used as the display name because Provider configuration does not include catalog metadata.
</ResponseField>

<ResponseField name="data[].created_at" type="string">
  The Unix epoch when the Provider does not supply a release date.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Always `false`; the configured workspace catalog is returned as one page.
</ResponseField>

<ResponseField name="first_id" type="string | null">
  The first configured model ID, or `null` when the catalog is empty.
</ResponseField>

<ResponseField name="last_id" type="string | null">
  The last configured model ID, or `null` when the catalog is empty.
</ResponseField>

```json Response
{
  "data": [
    {
      "type": "model",
      "id": "kimi-k2.5",
      "display_name": "kimi-k2.5",
      "created_at": "1970-01-01T00:00:00Z",
      "max_input_tokens": null,
      "max_tokens": null,
      "capabilities": null
    }
  ],
  "has_more": false,
  "first_id": "kimi-k2.5",
  "last_id": "kimi-k2.5"
}
```

Returns `503` when the workspace has no configured LLM Provider:

```json 503 Response
{
  "error": {
    "type": "api_error",
    "message": "This workspace has no LLM provider configured"
  }
}
```

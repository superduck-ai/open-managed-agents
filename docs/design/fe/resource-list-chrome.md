# 资源列表页头、空态与未找到

Environments、Vaults、Memory、Deployments、Sessions、Agents、Skills、Files、Members、Organization、API keys 和 Webhooks 使用同一套列表外观。页头、空态和未找到只对齐外观，不改这些控件的路由和接口。列表分页见下文。

## 页头与表格

- 智能体、会话、环境、部署、凭证保险库和记忆存储列表使用控制台全宽容器：桌面左右 `lg:px-8`、上下 `py-6`，小屏左右 `px-6`。页面内部不再叠加最大宽度或横向留白。
- 列表沿用全局 shadcn 语义主题，浅色主背景为纯白，深色随全局主题；会话列表不使用详情工作区的 `session-route-theme`。搜索与筛选使用 `bg-background`、`h-9`、`text-sm`。
- 智能体、会话、环境、部署、保险库、记忆存储以及保险库内的凭证表共用表格行交互与样式：表头 `h-10`，数据单元格在这些列表的行上显式设为 `h-11`；共享 `DataTableCell` 默认仍为 `h-10`，其他资源列表的行高保持不变。正文 `text-sm`、ID `font-mono text-xs`，统一 hover、selection 和行菜单。环境页同样使用共享页头及分页。上述表格最小宽度统一为 `1080px`，窄屏仅表格容器横向滚动，避免名称与状态列挤压重叠。

- 标题 `28px` / `font-semibold`，说明 `15px` / `leading-5`。宽屏主按钮在右上角，高度 `h-9`。窄屏页头改成纵向排列，按钮落到标题下面，避免和标题重叠。
- 标题和筛选之间 `mb-5`，筛选和表格之间 `mb-7`。没有筛选的列表把页头间距设为 `mb-7`，使标题到表格的距离与筛选到表格一致。
- 表格只有行分隔，没有外层圆角边框，也不再使用卡片标题或图标井。
- 共享 ID 复制入口在触屏或粗指针下常显；精确指针保留悬停与键盘焦点显示。按钮使用原有预留空间，不覆盖 ID，也不改变复制值。
- Files 的非空列表保留 `920px` 最小宽度与局部横向滚动。加载、空数据和错误状态按可用宽度显示，不展示空表头；错误信息允许换行，重试入口和面板完整边界必须可见。重试恢复数据后重新显示表头。

## 空态与创建弹窗

- 空列表是居中图标、标题和一句话。这句话的动词与页头主按钮相同，空态不再放第二个按钮。
- 创建弹窗标题 `22px` / `font-semibold`。取消在左，提交在右，提交文案与页头主按钮相同。
- API key 页头、弹窗标题和提交都是 “Create API key” / “创建 API 密钥”。Webhook 三处都是 “Create webhook endpoint” / “创建 Webhook 端点”。邀请三处都是 “Invite” / “邀请”。

## 列表分页与删除补位

控制台资源列表共用 `consoleResourceListLimit`，每页 15 条：Sessions、Agents、Deployments、Environments、Vaults、Memory、Files、Skills 和 Batches。Sessions、Deployments、Environments、Vaults 和 Memory 经 `listManagedEntities` 带上这个 `limit`；Files、Skills 和 Batches 使用同一个常量。Agents 列表页也用它；只读第一页的 Agent 选择器仍请求 20 条。接口用 `page` / `next_page` 游标翻页，Files 和 Batches 用 `after_id` / `before_id`。翻页条统一为同一套带边框的 `outline` / `icon-lg` 按钮，边框用 `border-foreground/30`。上一页或下一页禁用时，边框粗细和颜色保持不变，只把箭头改成浅色。按钮中间显示当前页，页码来自客户端游标历史或 `pageIndex`。列表响应没有总行数，所以不显示总页数。Agents 搜索把已加载结果按同样的页大小在本地切片，这一段可以按已加载条数显示总页数。省略 `limit` 时服务端默认仍是 20，上限 1000。删除成功后，以及归档会让该行离开当前查询时，用同一游标重新请求当前页，把下一行补进空位。重取失败不撤销已经成功的删除或归档，本地去掉该行并另报列表错误。重取结果为空且还有上一页时，退回上一页，避免停在空白页。Agents 的默认 Active 列表在归档后同样重取当前页。Skills 删除后会让当前页查询失效并重取。Files 和 Batches 列表没有删除。

## 未找到与工作区名称

- Agent 和 Session 不存在时使用同一块：标题、一句包含资源 ID 的说明、返回列表的链接。文案跟随当前语言。版本不存在和操作失败仍使用 alert。
- 这些页面及批处理空态上的工作区显示名如果正好是 `Default`，中文界面显示“默认”；用户自定义名称保持原值。
- 成员说明、表头、角色，组织设置字段和 API 密钥开关，侧边栏工作区显示名与账号角色，以及 Skills、Webhooks 里走文案表的句子，都跟随当前语言。组织 ID 和工作区 ID 保持原值。成员说明里的组织名保持用户保存的名称，包括名为 `Default` 的组织；只有缺少组织名时才回退到工作区显示名。

## 列表外观验收

逐个检查智能体、会话、环境、部署、保险库、保险库内凭证和记忆存储，在 2048px、1440px、390px 及深色主题下截图。对齐主背景、左右留白、标题、36px 控件和 44px 数据行，同时检查 Files、Skills、MCP 和成员等非托管列表仍使用默认 `h-10`（40px）高度配置；窄屏只能在表格容器内横向滚动。另检查搜索与 Escape 清空、筛选菜单、行菜单及 Escape 关闭。环境列表加载期必须复用稳定的空数据引用，避免 TanStack Table 在搜索或翻页时反复自动重置。

## Webhook 页面补充（2026-10-26）

成功返回空列表时仅保留页头创建入口与空态图标、标题，隐藏无数据可检索的搜索框、空表头、重复说明及第二个创建按钮。已有端点时保留 ID 搜索和排序；加载、错误和无匹配状态按容器宽度显示，不继承非空表格的 `880px` 最小宽度。名称与 URL 在同一个单元格上下排列，限制宽度后省略；详情保留完整 URL 和描述，描述中的连续长词允许换行。搜索与排序由独立的 `WebhookList` 展示组件持有，管理组件负责请求、选择目标及操作弹窗。

创建弹窗复用 `DialogClose` 提供取消，提交中取消和关闭入口同步禁用，沿用既有 Escape/遮罩关闭保护。草稿和错误在退出完成后清空，失败仍保留输入与所选事件。外层使用 `overflow-clip`，避免键盘聚焦列表末项时滚走标题和关闭按钮；事件列表在内部滚动，标题和底部操作保持可达。事件目录、选择逻辑、校验和 API 合同不变。

验收覆盖真实空列表与创建弹窗桌面/窄屏、隔离长名称列表与长描述详情、加载/错误/无匹配，以及 `390×480` 下聚焦末项后的标题、关闭与取消。正常弹窗过渡保留 `180ms`；减少动态效果时为零。真实页面仅打开/取消；提交中、错误恢复与草稿重置使用组件测试，不为视觉验收创建端点或披露密钥。

## 记忆与保险库详情补充（2026-10-26）

添加记忆弹窗复用共享 Dialog，限制在视口高度减去两侧间距内，标题与操作固定，路径和长正文在内部滚动。外层使用 `overflow-clip`，提交中禁用字段、取消和关闭，拒绝重复提交及 Escape 关闭；失败保留路径与正文，取消保留草稿至退出完成。详情页将添加入口传给 Base UI 的 `finalFocus`，关闭后返回原按钮。普通记忆编辑器使用浏览器原生 Tab 焦点顺序，不显示“Tab 插入缩进”的失实提示；正文统一 `text-sm`，不额外增加手机字号。

保险库凭据为空时仅保留详情页头添加入口与共享空态，不显示空搜索、空表头、重复按钮和同义说明。有数据时保留 ID 搜索。接口只返回未归档凭据，删除结果相同的“全部／活跃”筛选；可见凭据过滤与归档后移除行为保持。加载状态按容器宽度显示，非空表格继续 `900px` 最小宽度和局部滚动。凭据创建移除与标题重复的用途说明，保留 OAuth 编辑的操作说明与凭据共享告知。

视觉验收使用现有存储/保险库，添加长记忆只填写本地示例草稿后取消，不创建、修改或删除资源。另检查 `390×480` 长正文滚动、取消焦点、提交挂起和失败状态；提交状态通过组件测试覆盖。

凭据高级字段用 `0.5px` 顶部分隔线与可折叠标题组织，不在表单内再叠外框。箭头保留 `200ms ease-out` 旋转，减少动态效果时关闭过渡。网络选项使用中性选中态、`0.5px` 边框和完整键盘焦点提示；可见标签直接提供名称。MCP 地址字段的尾部按钮取消负外边距，避免在窄屏滚动区产生多余横向宽度。

凭据取消、关闭和 Escape 先关闭 Base UI Dialog，退出完成后才通知父级卸载，草稿在退场时保持。普通保存中禁止关闭及重复提交，字段同步禁用；滚动仍交给原来的 `div`，内部无边框 `fieldset` 仅承担禁用语义，避免 flex 中 fieldset 的溢出侵入固定操作区。等待 OAuth 时仍允许取消并立即关闭授权弹窗，之后完成控制台弹窗的退出；OAuth 成功及保存成功回调沿用原合同，不能据本轮手动关闭验收声称真实授权链路已验收。

## 批处理无数据时的表格结构

批处理列表只在成功载入有效行时显示列头与列宽定义；首屏加载、失败和空列表各自显示反馈，不保留没有可用操作的禁用分页。失败保留重试，重试成功恢复原四列。后续页即使为空或失败仍保留分页，可返回上一页，不能为精简空态切断导航。已有数据的行操作、选择、详情和分页合同保持。
